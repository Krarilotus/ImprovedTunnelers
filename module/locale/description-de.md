# Verbesserte Tunnelgräber

Verbessert die Zielwahl, Zusammenarbeit und Reaktion von Tunnelgräbern auf Kampfbefehle. Sie können weiter in Richtung feindlicher Befestigungen graben und an KI-Überfällen teilnehmen. Tunnelschaden, vorübergehende Baubeschränkungen nach einem Durchbruch und das Verhalten der Tunnelgräber sind anpassbar.
