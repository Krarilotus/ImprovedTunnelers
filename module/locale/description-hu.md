# Fejlesztett alagútásók

Javítja az alagútásók célpontválasztását, együttműködését és harci parancsokra adott reakcióját. Folytathatják az ásást az ellenséges védművek felé, és részt vehetnek az MI portyáiban. Az alagútomlás sebzése, a rés utáni ideiglenes építési korlátozások és az alagútásók viselkedése testreszabható.
